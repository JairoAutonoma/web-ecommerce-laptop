Todos nuestros productos incluyen una garantía de 2 años que cubre defectos de fabricación. Esta garantía incluye:

  • • Reparación o reemplazo de componentes defectuosos
  • • Asistencia técnica especializada
  • • Soporte telefónico y en línea 24/7
  • • Recogida a domicilio para reparaciones (aplican condiciones)

Para solicitar una reparación bajo garantía, sigue estos pasos:

  1. 1. Contacta a nuestro centro de soporte por teléfono o chat en vivo
  2. 2. Proporciona el número de serie de tu producto
  3. 3. Describe el problema técnico que estás experimentando
  4. 4. Nuestro equipo validará la cobertura de garantía
  5. 5. Coordinaremos la recogida o te indicaremos el centro de servicio autorizado más cercano

Sí, ofrecemos soporte técnico remoto para la mayoría de problemas de software y configuración. Nuestros técnicos pueden:

  • • Diagnosticar problemas de software de forma remota
  • • Ayudar con la instalación y configuración de drivers
  • • Optimizar el rendimiento de tu equipo
  • • Resolver problemas de conectividad y red
  • • Realizar mantenimiento preventivo del sistema

Este servicio está disponible de lunes a domingo, de 8:00 AM a 10:00 PM.

El tiempo de reparación varía según el tipo de problema:

  • Reparaciones simples: 2-3 días hábiles (limpieza, software, actualizaciones)
  • Reparaciones de hardware: 5-7 días hábiles (pantallas, teclados, componentes)
  • Reparaciones complejas: 7-14 días hábiles (tarjetas madre, problemas eléctricos)
  • Garantía de fabricante: 10-15 días hábiles (envío a centro autorizado)

Ofrecemos equipos de reemplazo para reparaciones que tomen más de 5 días hábiles (sujeto a disponibilidad).

Si tu laptop se sobrecalienta, te recomendamos seguir estos pasos:

  1. 1. Verifica la ventilación: Asegúrate de que las rejillas de ventilación no estén obstruidas
  2. 2. Usa una base refrigerante: Mejora la circulación de aire
  3. 3. Limpia los ventiladores: Usa aire comprimido para eliminar el polvo
  4. 4. Actualiza controladores: Asegúrate de tener los últimos drivers
  5. 5. Controla procesos: Cierra aplicaciones que consuman muchos recursos

Si el problema persiste, contacta a nuestro soporte técnico para una evaluación más profunda.
